# 店规适配层技术规格书（电商平台图片导出）

## 1. 背景

换衣引擎输出为 RGB 商品图（默认 `1024x1024` / `2048x2048`，白底或透明）。电商平台对商品图有严格合规要求：纯白底、无阴影、主体居中、比例 `1:1`、无文字 / Logo / 水印、文件大小受限。**店规适配层**在导出前按目标平台做预处理，保证图片可直接上传。

## 2. 平台硬性限制

| 平台 | 最大文件 | 尺寸要求 | 背景 / 内容要求 |
|------|---------|---------|----------------|
| **Shopify** | 20 MB | 最佳 `2048x2048` 正方形；最大 `5000x5000` 或 25 兆像素 | 白底，无文字 / 水印 |
| **亚马逊** | 10 GB | 最长边 ≥ `1000`（开启缩放）；最大 `10000` | 纯白 RGB(255,255,255)，产品占画面 ≥ 85%，无文字 / Logo / 水印 |
| **速卖通** | 5 MB（主图 / 营销图 / 变体图） | 主图 ≥ `800x800` | 白底，无文字 / 水印 |

## 3. 店规适配层模板（平台预处理）

| 平台 | 处理 | 导出 |
|------|------|------|
| **Shopify** | 居中裁剪 `2048x2048` | 高质量 JPEG，强制 ≤ 5 MB（< 上限 20 MB，加载更快） |
| **亚马逊** | 居中裁剪 `1600x1600`（开启缩放） | 纯白 (255,255,255) 填充，JPEG（≤ 10 GB 无需压） |
| **速卖通** | 居中裁剪 `800x800` 或 `1000x1000` | JPEG，强制 ≤ 4.5 MB（< 上限 5 MB） |

## 4. 实施要点

- **输入**：换衣引擎输出 `PIL.Image`（RGB，默认 1024 / 2048 边长）。
- **纯白底**：透明或带阴影区域填充为 `RGB(255,255,255)`；去阴影、去背景杂色。
- **居中裁剪**：按平台目标边长做 `center crop`（保持 `1:1`）；超出部分裁掉。
- **主体占比（亚马逊 ≥ 85%）**：先做主体检测 / 白边裁切，再保证主体居中占画面 ≥ 85%。
- **文件大小控制**：JPEG quality 从高到低递减直到 ≤ 平台上限（Shopify ≤ 5 MB、速卖通 ≤ 4.5 MB）；亚马逊仅需 ≤ 10 GB，`quality=95` 即可。
- **输出**：按平台独立子目录 / 文件名，含平台后缀便于识别。

## 6. 验收

- 每平台输出：白底（255,255,255）、`1:1`、主体居中、无文字水印、文件大小在平台上限内。
- 亚马逊输出：产品占画面 ≥ 85%，最长边 ≥ 1000。
