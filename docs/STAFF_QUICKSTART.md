# 员工快速上手 · Atelier 批量上身

目标：把平铺图或幽灵模特图，一键变成正面模特成品图，再下载或推到商品页。

## 登录

打开店铺后台「试衣工作台」。账号口令由环境变量设置：

- 管理员 `STORE_ADMIN_PASSWORD`
- 理货 `STORE_STAFF_PASSWORD`

未设置时服务端随机生成并打印到启动日志（多 worker 下各 worker 共享同一口令）。

## 四步出图

1. 选底座：女装、男装、女童、男童、婴幼儿。童装会按文件名自动识别 baby / boy / girl。
2. 拖入服装图：一次可拖几十到上百张。只出正面，不出侧面和背面。
3. 点「一键生成」。右侧队列显示进度。
4. 完成后点下载，或「推送到商品页」。成品长边 2048px，默认白底 JPEG，可改 PNG 透明底。

## 换底座

「模特底座」页上传自家模特正面站姿图。手臂微张、白底、头到大腿的构图最稳。保存后，新批次都会穿到这张底图上。

## 注意

- 平铺图尽量白底、衣服铺平、无衣架阴影
- 文件名带 `women` `men` `girl` `boy` `baby` 可自动选受众
- 失败任务看队列红色状态，改图后重新拖入即可
